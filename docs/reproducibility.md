# Reproducibility

This document draws one distinction carefully, because the article insists
on it: **software-pipeline reproducibility** (this repository runs the same
way every time, its arithmetic matches the article's worked example, and its
reference execution regenerates every simulation number the article prints)
is different from **empirical validation** (evidence about real
municipalities), which neither the article nor this repository claims.

| Evidence | Where in the article | Regenerated by |
| --- | --- | --- |

## The reference execution

- **Pre-specification.** The hypotheses H1–H8, their thresholds, and the
  decision rules were written to `configs/protocol/hypotheses.yaml` before the
  evaluation code existed.
- **Seed separation.** Development and debugging used seeds 1000–1009 only.
  The reported execution uses seeds 0–29 and was run once, after the
  configuration was frozen. Four implementation defects found on development
  seeds, and their corrections, are listed in Supplementary Section S1.4.
- **Common random numbers.** A seed fixes every exogenous draw (arrivals,
  requirements, outcome and fault draws, sensor noise, attrition times,
  machine-reliability paths, the order of hires), so all five policies are
  compared on identical streams.
- **Determinism.** `run_one(seed, scenario, policy)` is a pure function of
  its arguments; `tests/integration/test_protocol_engine.py` checks this.
- **Provenance.** Every execution writes `config.json` (every parameter),
  `runs.jsonl` (every run record), `summary.json`, and `hypotheses.json`.
  The article's tables and Figure 4 are generated from those files, and
  `audit_numbers.py` checks every simulation number quoted in the prose.
- **Cost.** 450 runs take 10 to 13 minutes on a 12-core workstation.

## What is NOT reproducible, because it does not exist

- **Measurements of any municipality.** The testbed is synthetic; its
  parameters are illustrative and its practitioners simulated.
- **Calibration against real municipal data.** `sim.calibration.sources`
  documents candidate open-data sources as metadata only.
- **The judgment parameters** (`learn_i`, hybrid `phi_m`, supervision ratios,
  certification hours) and the retention parameters of the proficiency model
  have not been elicited or fitted. Supplementary Section S6 specifies the
  elicitation protocol; it has not been run.

## Determinism notes for the core library

- `sim.calibration.sources.synthetic_demo_tasks(n, domain, service, seed)` is
  deterministic given the same seed.
- `civicworkos.solver.rebalance.solve_rebalance` calls CBC with a bounded time
  limit (`CIVICWORKOS_SOLVER_TIME_LIMIT_SECONDS`, default 60 s); a large,
  highly symmetric instance may return a different but feasible integer
  solution if the search is interrupted before proving optimality.
